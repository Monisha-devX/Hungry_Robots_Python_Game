# Hungry_Robots_Python_project

Hungry robots project implemented using python

 # About the Project

Hungry Robots is a simple text-based game developed using Python. The player must escape from hungry robots and make them collide with each other to survive.

 # Features

- 2D game board (50 × 24)
- Player movement in 8 directions
- 5 robots
- 30 random walls
- 6 teleport chances
- Robot movement and collision detection
- Easy Mode gameplay

 # Game Controls

Key| Action
Q| Move Up-Left
W| Move Up
E| Move Up-Right
A| Move Left
S| Stay
D| Move Right
Z| Move Down-Left
X| Move Down
C| Move Down-Right
T| Teleport
QUIT| Exit Game

 # Technologies Used

- Python
- Random Module
- 2D Lists
- Functions
- Conditional Statements
- Loops

# How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python hungry_robots.py

# Objective

Move strategically, avoid the robots, and make them collide with each other to eliminate them.
